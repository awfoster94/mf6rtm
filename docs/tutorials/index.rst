Tutorials
=========

Worked examples of reactive transport modeling with mf6rtm. The first three
build on an existing MODFLOW 6 transport model with the transport-first
:meth:`~mf6rtm.mup3d.base.Mup3d.from_mf6` workflow; the last shows the classic
``Mup3d`` workflow for full control over the flow and transport setup.
