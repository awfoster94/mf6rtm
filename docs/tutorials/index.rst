Tutorials
=========

Worked examples of reactive transport modeling with mf6rtm. The quickstart uses
the transport-first :meth:`~mf6rtm.mup3d.base.Mup3d.from_mf6` workflow; the
pyrite-oxidation examples use the classic ``Mup3d`` workflow on structured and
unstructured (DISV) grids.
